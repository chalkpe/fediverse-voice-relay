# 초코픽 통화 인프라 대여

초코픽은 자체 LiveKit을 직접 사용하거나, 독립 릴레이에서 통화 인프라를 대여할 수 있습니다. 초코픽은 다른 서버에 통화 인프라를 제공하지 않습니다.

릴레이 제공자는 `client add --origin`에 이용할 초코픽 서버의 공개 HTTPS origin을 입력합니다. 발급 결과에서 해당 `origin`과 `secret`을 확인하고, 초코픽 서버 관리자에게 릴레이 주소와 시크릿을 전달합니다. 릴레이 주소는 제공자의 `secrets/config.json`에 설정한 `publicUrl`입니다.

초코픽 관리자는 관리 화면의 **통화 인프라 대여**에서 **대여하기** 항목에 릴레이 주소와 시크릿만 입력합니다. 초코픽은 서버 설정의 공개 주소에서 자체 origin을 계산합니다. 저장한 릴레이에서 **연결·승인 확인**을 눌러 승인 여부와 수용량을 확인합니다.

시크릿을 교체하면 이전 시크릿은 즉시 무효화됩니다. 릴레이 제공자는 새 시크릿을 해당 서버 관리자에게 전달합니다. 관리자는 새 시크릿을 입력하고 연결을 다시 확인합니다.
